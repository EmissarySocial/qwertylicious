Qwertylicious is a Fediverse application for publishing long-form text content like blogs and newsletters. Authors can publish some text publicly, and can reserve other content for paid subscribers.

## Build with Emissary
Bandwagon is a small social app build on [Emissary, the social web toolkit](https://emissary.dev). You must [install Emissary](https://emissary.dev/installation) on a server first, before using Bandwagon.

### Installing
To install Qwertylicious on your own Emissary server directly from this repository, just open your [Emissary setup console](https://emissary.dev/setup-console), navigate to **Server Settings > Packages**, and add a new Git adapter that points to: `https://github.com/EmissarySocial/qwertylicious.git`
